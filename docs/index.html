A / KEEP A REFERENCE

Anchor

Allow the decoder to adapt while staying close to a recent reference. A periodically refreshed anchor gives learning continuity as the action representation changes.

The reference decoder is refreshed periodically.

H / GIVE COORDINATION STRUCTURE

Hoyer

Encourage selective actuator participation instead of diffuse connections everywhere. Hoyer regularization shapes more concentrated synergy patterns.
